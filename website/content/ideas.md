The QRL Ecosystem Index is most useful when it shows both what exists and what is still missing. This page compares independent artifact types and use-case categories for listings that support QRL 2.0, then highlights gaps and areas with only one implementation.

This is not an official roadmap or endorsement list. It is a living prompt for the community: if a project already exists, add it to the index; if it does not, consider building it.
